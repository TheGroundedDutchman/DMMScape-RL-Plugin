# DMMScape Glossary (Plugin)

- **Target**: A task location or objective sent from the webapp to display in-game.
- **Progress**: Player completion state collected in RuneLite and synced to the backend.
- **Sync Token**: Short-lived token used to authenticate plugin API calls.
- **Overlay**: In-game markers and minimap indicators for current targets.
- **Delta Sync**: Send only changed data instead of full payloads.
